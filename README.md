# 🛍️ Customer Shopping Behavior Analysis  
**End-to-End Data Analytics Project | Python • SQL Server • Power BI**

---

## 📘 Project Overview  
This project analyzes **customer shopping behavior** for a retail company aiming to improve **sales, customer satisfaction, and loyalty**.  
The goal was to identify **key behavioral patterns**, such as the impact of **discounts, reviews, seasons, and subscription status** on purchase decisions.

---

## 🎯 Objectives  
- Identify and understand **customer segments** and spending patterns  
- Evaluate **discount effectiveness** and **review-driven sales**  
- Analyze **subscription impact** on repeat purchases and loyalty  
- Build an **interactive Power BI dashboard** for executive insights  

---

## 🧠 Tech Stack  
| Tool | Purpose |
|------|----------|
| 🐍 **Python (Jupyter Notebook)** | Data cleaning, preprocessing, and feature engineering |
| 🗃️ **SQL Server** | Structured data storage and business query analysis |
| 📊 **Power BI** | Dashboard development and visualization |
| 📚 **Libraries** | Pandas, NumPy, Matplotlib, Seaborn |

---

## ⚙️ Project Workflow  

### 1️⃣ Data Preparation (Python)  
- Imported raw CSV data using Pandas  
- Handled null values, dropped duplicates, standardized column names  
- Created new features such as `age_group` and `purchase_frequency_days`  
- Exported cleaned dataset to SQL Server for further analysis  

### 2️⃣ Data Analysis (SQL Server)  
- Conducted exploratory and business-focused queries to derive insights:  
  - Revenue by gender and age group  
  - Discount usage vs. spending  
  - Subscriber vs. non-subscriber revenue comparison  
  - Product rating and top product performance  
  - Customer segmentation: New, Returning, Loyal  

### 3️⃣ Visualization (Power BI)  
- Built an **interactive Power BI dashboard** displaying:  
  - Sales and revenue by demographics  
  - Purchase frequency, discount dependency, and subscription trends  
  - Top-performing categories and customer loyalty insights  

### 4️⃣ Reporting  
- Compiled insights and recommendations into a **business report** for stakeholders  

---

## 📈 Key Insights  
🔹 **Subscribers** spend significantly more than non-subscribers  
🔹 **Express shipping users** tend to make higher-value purchases  
🔹 **Top-rated products** correlate with repeat buyers  
🔹 **Discount-heavy categories** increase volume but impact margins  
🔹 **Age group 30–40** contributes the highest revenue  

---

## 💡 Business Recommendations  
✅ Strengthen **subscription-based programs** to boost loyalty  
✅ Launch **targeted campaigns** for high-value customer groups  
✅ Optimize **discount strategies** to protect profit margins  
✅ Promote **top-rated and best-selling products** in marketing  
✅ Enhance **customer experience** through faster delivery options
